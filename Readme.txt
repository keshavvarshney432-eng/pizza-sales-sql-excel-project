# 📊 Pizza Sales Analysis (SQL + Excel)

## 🔷 Project Overview
This project focuses on analyzing pizza sales data using SQL and presenting meaningful business insights through an interactive Excel dashboard.

## 🔷 Tools Used
- SQL
- Microsoft Excel

## 🔷 Key Insights
- Highest sales observed during peak hours and weekends
- Identified top-performing and low-performing pizzas
- Revenue contribution analyzed by pizza category and size
- Order trends analyzed on daily and hourly basis

## 🔷 SQL Analysis
The following SQL queries were used to calculate KPIs and trends:
- Total Revenue
- Average Order Value (AOV)
- Total Orders
- Total Pizzas Sold
- Sales Trends (Daily & Hourly)
- Top & Bottom Selling Pizzas
