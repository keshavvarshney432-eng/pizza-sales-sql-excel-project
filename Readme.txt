Pizza Sales Analysis Project (SQL + Excel)

This project focuses on analyzing pizza sales data using SQL and presenting key business insights through an interactive Excel dashboard.

Key Highlights:
- Performed data analysis using SQL queries
- Calculated important KPIs such as Total Revenue, Total Orders, and Average Order Value
- Identified sales trends and top-performing products
- Built a visual dashboard in Excel for better understanding of insights

Tools Used:
- SQL
- Microsoft Excel

Files Included:
- dataset.csv (raw data)
- queries.sql (SQL analysis)
- dashboard.xlsx (Excel dashboard)
